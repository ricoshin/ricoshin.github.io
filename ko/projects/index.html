ICLR 2022

Sparse DETR: Efficient End-to-End Object Detection with Learnable Sparsity
Wuhyun Shin*, Byungseok Roh*, JaeWoong Shin*, Saehoon Kim (*: 공동 1저자, equal contribution)

논문 (arXiv)ICLR 포스터·발표코드 (GitHub)

목표
Deformable DETR의 메모리·연산 비용을 더 줄이면서 성능도 높이는 방법 제안
기존 방법
key sparsification으로 attention complexity를 줄이지만 dense query는 그대로 사용
주요 작업
  • decoder가 실제로 참조할 encoder token만 학습으로 골라 갱신하는 learnable query sparsification 제안 (메모리·속도 개선)
  • encoder block의 gradient vanishing을 막는 auxiliary loss 추가 (성능 개선)
결과
encoder token 10%만으로 COCO에서 Deformable DETR보다 높은 성능, 전체 연산량 38% 감소, FPS 42% 향상
역할
아이디어, 논의, 실험, 논문 작성

Spatially Consistent Representation Learning

논문 (arXiv)코드 (GitHub)

목표
detection·segmentation 같은 localization task에 맞는 backbone 초기값을 pre-training으로 학습
기존 방법
contrastive learning이 두 augmented view를 서로 다른 crop 영역에서 만들어, local representation의 spatial consistency를 놓치기 쉬움
주요 작업
두 augmented view에서 이미지의 같은 영역(같은 semantics)을 골라, 그 영역끼리 representation이 일치하도록 학습하는 방법 제안
결과
localization task에서 BYOL·SwAV 같은 global matching 방법보다 높은 성능, PASCAL VOC detection에서 ImageNet supervised pre-training 대비 +4.0 AP, BYOL 대비 +2.2 AP
역할
아이디어부터 논문 제출까지 전 과정 참여, GitHub 코드 정리·공개
